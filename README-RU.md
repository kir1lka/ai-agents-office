# Живой AI-офис

Эта локальная версия обоев переведена на русский. Сцена с фургоном ТЦК, её случайный запуск, военные, реплики и кнопка полностью удалены. Оригинальные `index.html` и `project.json` сохранены в папке `backup-original`.

## Как это работает

- **Codex** — основной белый персонаж. Получает настоящую задачу в приложении Codex → приезжает, садится за стол и работает. Большая панель слева показывает текущую задачу, операцию, файл или короткую команду и последнее сообщение о ходе работы.
- **Помощники Codex** — отдельные фиолетовые персонажи. Они появляются, когда Codex действительно создаёт подагентов. Над головой — имя, например TURING. После завершения задачи отдыхают до пяти минут и уезжают. Сам мост помощников не запускает.
- **ChatGPT** — постоянный зелёный житель офиса. В свободное время гуляет, сидит на диване, пьёт кофе и общается. Если открыто отдельное приложение ChatGPT, его работа приблизительно определяется по нагрузке процесса. Браузерные вкладки ChatGPT не отслеживаются.
- Персонажи ходят по офису, выходят на улицу, посещают кухню, общаются и взаимодействуют с котом. Новая работа возвращает Codex с обычного перерыва за стол.

Основной Codex представляет текущую работу приложения; одновременно запущенные обычные чаты объединены в этого персонажа. Его настоящие подагенты показаны отдельно. Вместимость — Codex, ChatGPT и до шести помощников.

## Подключение

На этом компьютере мост уже установлен и добавлен в автозапуск Windows. API-ключ, вход в дополнительный аккаунт и платный API не нужны.

1. Оставь эту папку на месте.
2. Запусти Wallpaper Engine и выбери **TheGrandees AI Office · RU · живой офис**. Рабочая копия устанавливается в `projects/myprojects/ai-office-ru-live` внутри папки Wallpaper Engine. Папка с исходниками нужна для локального моста.
3. Открой приложение Codex и отправь задачу в любом чате.
4. Через несколько секунд изменится статус Codex слева. Машине и персонажу нужно ещё немного времени, чтобы доехать и дойти до стола.
5. Для настоящих помощников дай Codex задачу, в которой нужны подагенты, например: «Раздели проверку проекта между двумя подагентами». Доступность и фактический запуск подагентов зависят от текущего режима Codex.

Claude и Ollama исключены, в том числе из демо. Кнопка **Демо** показывает только Codex и ChatGPT, если для них нет настоящих подключённых персонажей. Для наблюдения за реальной работой оставь демо выключенным. Если помощников много, карточки слева прокручиваются колёсиком мыши или стрелками над списком. Настройки закреплены сверху: сезон, погода, звук, демо и «Отдых / перекур». Нажатие отправляет персонажей на лавочку у фасада на 60 секунд; повторное нажатие возвращает их в офис. Реальные задачи Codex продолжают выполняться. Все надписи выполнены пиксельным шрифтом; внизу оставлен безопасный отступ 80 пикселей под панель задач Windows.

## Запуск и отключение моста

В проводнике можно щёлкнуть нужный `.ps1` правой кнопкой и выбрать «Выполнить с помощью PowerShell». Надёжный вариант — открыть PowerShell в этой папке и выполнить:

```powershell
# Запустить вручную, если мост выключен
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-office.ps1

# Скопировать текущие обои в Wallpaper Engine и включить их
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\apply-wallpaper.ps1

# Установить/восстановить запуск при входе в Windows
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-office.ps1

# Остановить до следующего запуска
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\stop-office.ps1

# Остановить и убрать из автозапуска
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\uninstall-office.ps1
```

Мост работает скрыто через установленный Python 3, без окна консоли. Ярлык автозапуска называется **AI Office Local**. Если перенесёшь папку, заново выполни `install-office.ps1` из нового места.

## Если персонажи не появляются

Открой в браузере http://127.0.0.1:7777/state. Должен появиться JSON с `scan: true` и списком `agents`. Это проверка локального моста; к интернету адрес не обращается.

- Адрес не открывается: запусти `start-office.ps1`.
- Есть Codex в JSON, но обои прежние или на украинском: Wallpaper Engine показывает другую копию. Выполни из папки с исходниками:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\apply-wallpaper.ps1
```

- Нет отдельного помощника: он должен быть действительно запущен Codex; декоративные помощники автоматически не создаются.
- ChatGPT в браузере работает, но зелёный персонаж отдыхает: браузерная активность не подключена.
- После обновления Codex статусы пропали: мост зависит от формата локальной истории Codex. Если приложение изменит этот формат, может понадобиться обновление моста.

## Данные и файлы

`office-bridge.py` читает локальные базы `~/.codex/thread_history_1.sqlite` и `~/.codex/state_5.sqlite` только для чтения. Базы Codex и его настройки не изменяются. Для большой панели считываются текущий запрос пользователя, публичное сообщение о ходе работы и метаданные действия (файл, короткая команда или название инструмента). Обоям передаются укороченные строки, состояние, имя подагента и короткое имя папки. Скрытые рассуждения и результаты инструментов не извлекаются. Данные обновляются примерно раз в секунду. Сервер слушает только `127.0.0.1:7777` и не имеет API для выполнения команд.

`tests/test_office_bridge.py` проверяет состояния и HTTP. Запуск: `python -m unittest discover -s tests -v`.

`apply-wallpaper.ps1` размещает только обои, шрифты, настройки и превью в локальной папке Wallpaper Engine. Мост продолжает запускаться из папки с исходниками. Отдельная локальная копия позволяет избежать проблем командной строки Wallpaper Engine с кириллицей в пути; Workshop-копия не перезаписывается.

Время, восход и закат сохранены по исходной логике Киева. Сезон, погода и звук переключаются кнопками справа и в свойствах Wallpaper Engine.

Исходный проект: https://github.com/AlexanderGrandees/thegrandees-ai-office.


## Дневные экраны

Вывеска называется «Офис AI-агентов». Экран слева показывает двух лидеров по времени задач за сегодня и мини-график по часам. Время Codex берётся из интервалов задач, пересечения обычных чатов не суммируются повторно. Именные подагенты учитываются отдельно. Это время задач, включая ожидание внутри них, а не измерение полезности сотрудника. Время ChatGPT приблизительное: наблюдаемые всплески активности приложения, сохранённые локально.

Вторая доска показывает токены за день из `token_usage_record` локальных журналов Codex: вход, выход и долю кэша. Каждый response_id учитывается один раз. Кэш уже входит во входные токены и повторно к сумме не прибавляется. Это количество токенов, а не стоимость или списание платной квоты. Учитываются доступные локальные сессии Codex; токены отдельного ChatGPT недоступны. При отсутствии записей показано «--».

День статистики — по Москве (UTC+3). Статистика обновляется примерно раз в пять секунд. JSON-наблюдения ChatGPT хранятся в `office-observed.json` возле моста; исходники и статистика Codex не изменяются.
